# Analysis Methodology – Fitness Operations and Member Analytics

## 1. Project Overview

This document explains the analytical approach used to develop the Fitness Operations and Member Analytics dashboard in Tableau.

The project explores gym membership demographics, workout preferences, calorie expenditure, water intake and workout frequency to provide an overview of fitness-related patterns among gym members.

## 2. Dataset Description

The analysis uses a gym dataset containing 973 member records.

The dataset includes demographic, physical fitness and workout-related attributes.

### Key Dataset Fields

- Age
- Gender
- Weight
- Height
- BMI
- Fat Percentage
- Maximum BPM
- Average BPM
- Resting BPM
- Session Duration
- Calories Burned
- Workout Type
- Water Intake
- Workout Frequency
- Experience Level

## 3. Tools Used

- **Tableau:** Data visualisation and interactive dashboard development.
- **CSV:** Source dataset.
- **Exploratory Data Analysis:** Examination of demographic and fitness-related patterns.

## 4. Key Performance Indicators

The dashboard presents five major KPIs:

| KPI | Value |
|---|---:|
| Total Members | 973 |
| Average Age | 38.68 |
| Average BMI Level | 24.91 |
| Total Calories Burned | 880,976 |
| Average Workout Frequency | 3.322 |

These KPIs provide a high-level overview of gym membership and fitness activity.

## 5. Dashboard Visualisations

### 5.1 Members by Workout Type

A bar chart compares the number of members participating in different workout categories:

- Cardio
- HIIT
- Strength
- Yoga

This visualisation helps identify workout preferences among gym members.

### 5.2 Water Intake Analysis

Box plots are used to examine water intake distribution across workout types.

They help compare the spread, median and variability of water consumption among members following different workout routines.

### 5.3 Gender Distribution

A pie chart displays the distribution of male and female gym members.

- Male Members: 511
- Female Members: 462

This provides an overview of the gender composition of the membership dataset.

### 5.4 Age Distribution of Gym Members

A bar chart illustrates the distribution of members across different ages.

This helps identify the age groups represented in the gym membership dataset.

### 5.5 Average Calories by Workout Type

A horizontal bar chart compares average calories burned across workout categories.

| Workout Type | Average Calories Burned |
|---|---:|
| Cardio | 885 |
| HIIT | 926 |
| Strength | 911 |
| Yoga | 903 |

HIIT records the highest average calorie expenditure among the four workout categories displayed.

## 6. Interactive Dashboard Filters

The dashboard incorporates interactive filters to support further exploration.

- **Gender:** Filter the analysis by male and female members.
- **Workout Type:** Explore individual workout categories.
- **Age Groups:** Analyse membership patterns across age groups.

These filters allow users to examine different segments of the gym membership dataset.

## 7. Key Analytical Observations

1. The dataset contains 973 gym members.
2. Male members account for 511 records, while female members account for 462.
3. The average age of gym members is 38.68 years.
4. The average BMI level is 24.91.
5. HIIT records the highest average calorie expenditure at 926.
6. The average workout frequency is approximately 3.32 days per week.

## 8. Business Interpretation

The dashboard provides a consolidated view of gym membership and workout-related metrics.

The visualisations can help gym management:

- Understand member preferences across workout categories.
- Examine demographic patterns within the membership base.
- Compare calorie expenditure across workout types.
- Explore water intake patterns.
- Evaluate workout participation and frequency.

These insights can support decisions related to fitness programmes, member engagement and workout planning.

## 9. Conclusion

This project demonstrates the use of Tableau to transform gym membership and fitness data into an interactive analytical dashboard.

By combining KPI indicators, demographic analysis and workout-related visualisations, the dashboard provides an accessible overview of gym operations and member activity patterns.
