# Fitness Operations and Member Analytics | Tableau

## Project Overview

This project presents an interactive Tableau dashboard designed to analyse gym membership patterns, workout preferences, fitness metrics and member demographics.

The dashboard provides an overview of gym operations through key performance indicators and visualisations, helping explore member participation, workout behaviour, calorie expenditure and fitness-related patterns.

## Project Objectives

- Analyse gym membership and demographic distribution.
- Understand member preferences across different workout types.
- Examine calorie expenditure across workout categories.
- Explore water intake patterns among gym members.
- Analyse age and gender distribution.
- Provide an interactive view of fitness and membership metrics.

## Dataset Overview

The dataset contains **973 gym member records** and 15 columns covering demographic information, physical attributes and workout-related metrics.

**Key attributes include:**
- Age and Gender
- Weight and Height
- BMI and Fat Percentage
- Maximum, Average and Resting BPM
- Session Duration
- Calories Burned
- Workout Type
- Water Intake
- Workout Frequency
- Experience Level

## Tools and Technologies

- **Tableau:** Dashboard development and data visualisation
- **CSV:** Dataset source
- **Data Analysis:** Exploratory analysis of membership and fitness metrics

## Dashboard Components

The dashboard includes the following visualisations:

1. **Members by Workout Type** – Displays member participation across Cardio, HIIT, Strength and Yoga.
2. **Water Intake Analysis** – Uses box plots to examine water intake distribution across workout types.
3. **Gender Distribution** – Shows the distribution of male and female members.
4. **Age Distribution of Gym Members** – Illustrates member distribution across age groups.
5. **Average Calories by Workout Type** – Compares average calorie expenditure across workout categories.

## Interactive Filters

The dashboard includes interactive filters for:
- Gender
- Workout Type
- Age Groups

These filters allow users to explore the dashboard from different membership and workout perspectives.

## Key Observations

- The dataset contains 973 members, with 511 male and 462 female members.
- Strength has the highest member count among the four workout types, followed closely by Cardio.
- HIIT records the highest average calories burned among the workout categories displayed.
- The average member age is approximately 39 years.
- The average workout frequency is approximately 3.32 days per week.
